# 🚬 Smoking and Health Analysis Dashboard | Power BI

## 📌 Project Overview

The **Smoking and Health Analysis Dashboard** is an interactive data visualization project developed using Microsoft Power BI. The primary objective of this project is to analyze smoking habits and explore their relationship with various health indicators and demographic factors.

The dashboard transforms raw data into meaningful visual insights, helping users understand smoking patterns, identify health-related trends, and explore the potential impact of smoking on overall health.

Through interactive charts, graphs, KPIs, and filters, this project provides a comprehensive overview of smoking-related data in an easy-to-understand format.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze smoking patterns across different demographic groups.
- Explore the relationship between smoking habits and health conditions.
- Identify trends and patterns in smoking-related health indicators.
- Compare health outcomes among smokers and non-smokers.
- Present complex data through interactive and visually appealing dashboards.
- Support data-driven understanding of smoking and public health.

## 📊 Dashboard Features

The dashboard includes interactive visualizations designed to provide insights into different aspects of smoking and health.

### 1. Key Performance Indicators (KPIs)
- Total number of individuals analyzed.
- Number of smokers and non-smokers.
- Smoking distribution percentage.
- Relevant health-related indicators.

### 2. Smoking Pattern Analysis
- Distribution of smokers and non-smokers.
- Comparison of smoking habits across demographic categories.
- Analysis of smoking frequency or intensity, where available.

### 3. Health Analysis
- Exploration of health conditions associated with smoking status.
- Comparison of health indicators between smokers and non-smokers.
- Identification of patterns in smoking-related health outcomes.

### 4. Demographic Analysis
- Analysis based on age groups.
- Gender-wise comparison, where available.
- Exploration of smoking trends across different population segments.

### 5. Interactive Dashboard
- Dynamic filters and slicers.
- Interactive charts and graphs.
- Cross-filtering between visual elements.
- Easy navigation for exploring different dimensions of the dataset.

## 🔄 Data Analysis Workflow

The project follows a structured data analysis process:

1. **Data Collection:** Obtaining the dataset containing smoking habits and health-related information.
2. **Data Cleaning:** Handling missing values, duplicate records, and inconsistent data using Power Query.
3. **Data Transformation:** Preparing and organizing the dataset for meaningful analysis.
4. **Data Modeling:** Establishing relationships between tables, if applicable.
5. **DAX Calculations:** Creating calculated measures and KPIs to support analysis.
6. **Data Visualization:** Designing interactive charts, graphs, and dashboard components.
7. **Insights Generation:** Analyzing the visualized information to identify important trends and patterns
